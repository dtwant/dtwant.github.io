Markdown Studio

Markdown Studio
#

Markdown、数式、Mermaid図を一つの画面で編集・確認できるローカルファーストのエディターです。3つの保存スロットはブラウザーへ自動保存され、再読込後も続きから編集できます。

[!TIP] 主な機能

  • 自動保存、Undo / Redo、復元できる編集履歴
  • 検索・置換、見出し・表・リスト・数式などの入力補助
  • Markdown / HTML / PDF書き出しとJSONバックアップ
  • スマートフォン用の編集・プレビュー切替、集中モード

データはこの端末のブラウザーへ保存されます。大切な文書は、書き出しメニューから定期的にJSONバックアップを保存してください。
