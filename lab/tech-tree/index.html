RPGのスキルツリーのように、知識やスキルの学習進捗を視覚的に管理するツールです。EXPを使ってスキルを解放していきます。

🎮 基本の遊び方

  1. + 100 EXP ボタンでEXPを獲得します（実際の学習の報酬として）
  2. ツリー上で 枠線のあるノード（available） をクリック → EXPを消費してスキルを解放
  3. 前提条件を満たしたノードだけが解放可能になります

🔍 ズーム & 移動

  • 移動: ツリーをドラッグ / スワイプ
  • ズーム: マウスホイール / +−ボタン / スマホでピンチ
  • CENTER: ツリーの中心に戻る

🔎 検索

  • 左パネルの 検索ボックス にノード名を入力すると、該当ノードが黄色でハイライトされ、自動でスクロールします

✏️ カスタマイズ

  • LAYOUT: ON → ドラッグ＆ドロップでノードの位置を自由に変更
  • LINK: ON → ノードをクリックして前提条件の接続/切断を操作
  • JSON EDITOR → ノードの追加、名前・コスト・色の変更などをJSONで直接編集

📊 進捗

  • プログレスバーで全体の解放率を確認できます
  • PURGE PROGRESSION で全ての進捗をリセット

🎨 ノードの色

  • 🟡 CORE: 基礎知識 / 🔵 FRONT: フロントエンド / 🟢 BACK: バックエンド / 🩷 CYBER: セキュリティ

💾 データはブラウザのlocalStorageに自動保存されます。📱 スマホでは ☰ ボタンでパネルを開きます。
