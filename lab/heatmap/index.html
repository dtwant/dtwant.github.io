日々の活動量や習慣の継続をGitHub風のヒートマップで可視化するツールです。過去52週間の記録を一覧できます。

📝 基本の使い方

  1. 下の + LOG ACTION (L1) ボタンを押すと、今日のレベルが1つ上がります
  2. + INTENSE (L2) を押すと、レベルが2つ上がります（最大 LVL 4）
  3. ヒートマップの各セルを直接 クリック/タップ してもレベルを変更できます（0→1→2→3→4→0の循環）

🎯 ゴールを設定する

  • 上部のプログレスバー横の EDIT ボタンで、1日の目標レベル（1〜4）を設定できます
  • 達成度がバーで表示されるので、毎日の目標管理に活用してください

📋 複数の習慣を管理する

  • 上部の + ADD タブをクリックして、新しい習慣を追加（例: 運動、読書、コーディング）
  • タブをクリックして習慣を切り替え。× DEL で現在の習慣を削除

📱 スマホ操作

  • セルを 長押し すると、レベルを直接数値で指定できます

🎨 その他

  • THEME: GREEN / PINK / BLUE のカラーテーマを切り替え
  • WEEKLY ACTIVITY: 直近12週の棒グラフで活動量のトレンドを確認
  • EXPORT / IMPORT: JSONでデータのバックアップと復元が可能

💾 データはブラウザのlocalStorageに自動保存されます。
